# tidymst: Read and Analyse NanoTemper Microscale Thermophoresis Exports

Read the Excel exports written by NanoTemper's MO.Affinity Analysis
software (MST traces, capillary scans, dose-response and fit results)
into tidy data frames, and analyse them: recompute normalised
fluorescence (Fnorm) from traces, fit Kd and Hill binding models, and
convert responses to delta Fnorm or fraction bound.
